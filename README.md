Play Pawng, a Pong type game I developed as a first project learning Unity.
Two pawns having the match of their lives (over and over again).

INSTRUCTIONS:
- Left pawn uses WASD to move.
- Right pawn uses ARROWS to move.
- The first pawn to get to 3 points win BUT BE CAREFUL, if you don't score before 20 seconds, the pawn with the ball in his half loses.

CONFIGURE:
- Change SIZE and SPEED cause ball can be pretty reactive.
- Change BALL COLOR just for fun.
